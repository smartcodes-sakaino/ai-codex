# フォントについて

`NotoSansJP-Regular.ttf` / `NotoSansJP-Bold.ttf` は Google の Noto Sans JP フォント(日本語サブセット)を、
[SIL Open Font License 1.1](https://openfontlicense.org/) の下で同梱しています。
修了証PDF(server/lms/certificate.ts)の日本語表示に使用しています。

元データ: https://fontsource.org/fonts/noto-sans-jp (woff2形式で配布されているものを、
pdfkit/fontkitが直接扱えるttf形式に変換して同梱しています)
